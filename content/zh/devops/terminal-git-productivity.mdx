# 终端 Git 效率提升

## 学完这篇你会掌握什么

- 通过 Git 别名、shell 自动补全、lazygit、tig、delta diff 查看器和 git-prompt 定制等工具，大幅提升终端 Git 操作效率。
- 理解 Git 别名 相关的概念
- 掌握 Shell 自动补全 相关的操作

## 先想一个问题

关于终端 Git 效率提升，你的理解可能停留在"知道怎么操作"，但说不清它为什么这样设计、边界在哪里。恰恰是这些说不清的地方，最容易在关键时刻出问题。这篇把终端 Git 效率提升从"会用"推进到"理解"。

## 一句话理解

终端是 Git 的原生环境，通过别名、专用工具和定制提示符，可将日常 Git 操作效率提升数倍。

## Git 别名

```ini
[alias]
  st = status
  co = checkout
  br = branch
  ci = commit
  di = diff
  lg = log --oneline --graph --all --decorate
  aa = add --all
  unstage = reset HEAD --
  undo = reset --soft HEAD~1
  ri = rebase -i
  tree = log --all --graph --oneline --decorate
  cleanup = !git branch --merged main | grep -v \" main\" | xargs -r git branch -d
  lines = !git log --author=\"$(git config user.name)\" --pretty=tformat: --numstat | awk '{ add += $1; subs += $2; loc += $1 - $2 } END { printf \"added: %s, removed: %s, total: %s\", add, subs, loc }'
```

## Shell 自动补全

**Bash**:
```bash
source /usr/share/bash-completion/completions/git
export GIT_PS1_SHOWDIRTYSTATE=true
```

**Zsh** (oh-my-zsh):
```zsh
plugins=(git gitfast)
```

**Fish** (内置补全):
```fish
abbr -a gst 'git status'
abbr -a gco 'git checkout'
abbr -a glg 'git log --oneline --graph --all --decorate'
```

## lazygit

```bash
brew install lazygit
cd my-project && lazygit
```

| 面板 | 快捷键 | 功能 |
|------|--------|------|
| 文件 | `Space` | 暂存/取消 |
| 文件 | `c` | 提交 |
| 分支 | `b` | 切换分支 |
| 提交 | `s` | Squash |

配置 delta 为分页器：`git.paging.pager: delta`。

## tig

```bash
brew install tig
tig            # 提交历史
tig status     # 状态
tig blame file # Blame
```

## delta — 增强 Diff

```ini
[core]
  pager = delta
[delta]
  side-by-side = true
  line-numbers = true
  syntax-theme = Dracula
```

特性：语法高亮、并排视图、行号、代码导航。

## git-prompt

```bash
export GIT_PS1_SHOWDIRTYSTATE=1
export GIT_PS1_SHOWSTASHSTATE=1
export GIT_PS1_SHOWUPSTREAM="auto"
PS1='\w$(__git_ps1 " (%s)")\$ '
```

或使用 starship：

```toml
[git_branch]
format = "on [$symbol$branch]($style) "
[git_status]
staged = "+\${count}"
modified = "!\${count}"
```

## git-branchless

```bash
brew install git-branchless
git sl       # 智能提交图
git undo     # 撤销上次操作
git restack  # 修复中断的依赖
git record   # 交互式暂存并提交
```
