# git-help 教程

## 先想一个问题

`git help <cmd>` 和 `git <cmd> --help` 打开的是同一套文档，区别只在渲染方式：前者调 man 页，后者在终端里输出。真正会卡住人的是环境问题——最小化镜像里没装 `git-doc`、`man` 不可用、以及 `git help --web` 需要的浏览器。

## 基本示例

```bash
git help rebase
```


## 特殊情况与边界

- `git help <command>` 和 `git <command> --help` 功能相同，前者调用 man 页面，后者在终端显示帮助文本（具体行为取决于配置）。
- `git help` 依赖系统的手册页系统，某些最小化安装的环境可能缺少 Git 文档包，需要额外安装。
- 用 `git help --guides` 可以查看 Git 的概念指南（如 gitworkflows、gitrevisions 等），不只是具体命令的帮助。
- `git help` 查阅的是本地文档，不需要联网，但文档版本与安装的 Git 版本一致，可能不是最新版本。
- 对于自定义别名，`git help <alias>` 会显示别名展开后的命令帮助，而不是别名本身的说明。
